# 📐 高数公式 + 例题 + 随机测验

一个打开即用的高等数学（上册）复习工具。单文件 HTML 应用，无需后端、无需联网、无任何外部依赖，双击即可在浏览器中运行。

## ✨ 功能特性

- **📚 公式库**：内置 63 条高数上册核心公式，覆盖 6 大分类：
  - 函数与极限（两个重要极限、等价无穷小、泰勒展开等）
  - 导数与微分（求导法则、链式法则、高阶导数等）
  - 微分中值定理（罗尔、拉格朗日、柯西、极值判定等）
  - 不定积分（基本积分表、换元法、分部积分等）
  - 定积分（牛顿-莱布尼茨、对称性、华里士公式等）
  - 微分方程（可分离变量、一阶线性、二阶常系数等）
  - 每条公式包含：名称、分类、公式内容、说明、常用变形、标签、收藏状态
- **📝 例题库**：内置 26 道典型例题，包含题目、分步解题过程、答案与易错点提醒
- **🎲 随机测验**：
  - 可选择题库范围：全部 / 只看收藏 / 指定分类
  - 先只显示题目，点击「显示答案」后查看解析
  - 「会了 / 不会」一键记录，自动统计测验次数与掌握率
  - 洗牌抽题，一轮内不重复，题库抽完自动提示
- **⭐ 收藏**：公式与例题均可收藏，收藏页集中查看、一键取消
- **⚙️ 设置**：导出 JSON 备份 / 合并导入 / 覆盖导入 / 二次确认清空全部数据

## 🔍 其他亮点

- 支持按名称、公式内容、说明、标签模糊搜索
- 公式与例题支持手动添加、编辑、删除
- 所有数据保存在浏览器 `localStorage`（键名 `math_formula_v1`），刷新不丢失
- 空状态友好提示，移动端优先设计，按钮点击区域 ≥ 44px
- 数学公式使用 Unicode 纯文本表示（∑、∫、√、lim、→ 等），不依赖 KaTeX 等外部库

## 🚀 使用方法

1. 下载或克隆本仓库
2. 双击 `高数公式+例题+随机测验.html` 在浏览器中打开
3. 开始学习！

也可以直接开启 GitHub Pages，通过链接在手机 / 电脑浏览器中访问。

## 🛠️ 技术栈

- 纯 HTML + CSS + JavaScript，单文件实现
- 无框架、无外部图片、字体或 CDN 依赖
- 数据持久化：localStorage
